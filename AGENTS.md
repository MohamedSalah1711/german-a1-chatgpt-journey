# Agent Instructions

Use this repo as a daily German A1 learning journal.

Before creating or editing a daily lesson, read:

- `START_HERE.md`
- `CURRENT_STATE.md`
- `progress.json`
- `MISTAKE_PATTERNS.md`
- latest files in `days/`
- `references/startbereit-a1-source-map.md`

Daily session requirements:

1. Start with a review of previous days before introducing new material.
2. Use exactly 10 verbs for the new day unless the learner explicitly asks for a different number.
3. Include examples for every verb; distinguish mapped textbook verbs from general A1 practice.
4. Include one focused grammar point and exercises.
5. Keep explanations learner-friendly in Arabic, with German examples.
6. Update progress files only after real study and assessment; then suggest a Git commit message.

Do not overwrite completed day files. If a day file already exists, append a correction or create the next day.

Checkpoint rules (as of 2026-10-13):

- The learner has already studied through **printed page 80** of Startbereit A1 (**PDF page 81**); resume at **printed page 81 / PDF page 82**, Lektion 3.
- Treat `progress.json.course_progress` as the bookmark; do not infer the next textbook page from GitHub day number.
- Day 001 is the first GitHub tracking day; it is not the learner's first A1 class.
- Only mark pages as studied on learner confirmation. Never infer mastery, grades, or completed textbook exercises.
- Before proceeding, diagnose previous grammar briefly (articles/plurals, Präsens, possessives, nicht/kein).
- A complete PDF is currently in this public repo; verify the right to redistribute it, and use the source map for planning.

Safety: Never overwrite CURRENT_STATE.md when only creating a worksheet. Never overwrite an existing day file. Never advance pages, mark verbs mastered or invent scores from generation alone.
